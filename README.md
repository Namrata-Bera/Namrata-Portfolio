# Namrata Bera — Portfolio

A responsive, static portfolio built with HTML, CSS and JavaScript. It can be opened directly from `index.html` or deployed to GitHub Pages, Netlify or Vercel as a static site.

## Files

- `index.html` — page structure and portfolio content
- `assets/css/style.css` — responsive layout, themes and motion
- `assets/js/script.js` — navigation, theme, filtering, reveal effects and contact form
- `assets/images/` — project illustrations
- `assets/certificates/` — place certificate files here
- `resume.pdf` — résumé PDF used by the website
- `resume.docx` — original editable résumé supplied for this portfolio

## Preview

Open `index.html` in a browser. The site does not require a build step or server. For consistent browser behavior, you may also serve this folder with any static web server.

## Deploy

- **GitHub Pages:** publish this folder (or its contents) from the repository's Pages settings.
- **Netlify / Vercel:** import the repository and set the publish/output directory to `portfolio` if this folder is nested in a larger repository. No build command is needed.

## Personalize before publishing

- Add verified project repository URLs and live demos to the project cards.
- Add exact Deloitte internship details only if the certification was also a separate internship.
- Add credential and certificate links in the certifications section.
- The contact form opens an email draft in the visitor's mail app; it does not send or store messages on a server.
- Check whether you want your phone number in the downloadable résumé before publishing it publicly.
